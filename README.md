# 📌 Login-OTP (Java + XML + PHP)

**Login with Phone Number & One-Time Password (OTP) without Database**  

**Technologies:** Java + XML + PHP

---

## 🚀 Overview

This project is a **simple OTP login system**:  

1. User enters their phone number.  
2. The server generates an OTP and sends it back.  
3. User enters the OTP on the second screen to verify.  

> ❗ This version works **without a database**. OTP is generated and returned instantly from the server.
